Banning a hue family is not design.

Lessons from a 4-lane design-genius audit. Banning reproductions instead of hues, avoiding premature gate short-circuits, and medium-aware slop tells.

case files — design ward

CASE №016design · gatesfixed

Ban the reproduction, never the hue

Scar
A rule "no orange accent" bans a color family outright — even when a heritage gold on ivory has a real derivation line. It cannot distinguish blanket harm from justified derivation.
Fix
Gate the default REPRODUCTION as a whole (AND-ed: banned band + flat bg + no derivation). Clears if it escapes any one.
Check
State 3 conditions AND-ed. If the gate says "never warm on cream", it is a hue ban, not a reproduction gate.
CASE №017design · auditsfixed

One gate passing ≠ the audit passed

Scar
A color gate only clears color. A site with generic blue passes color but still fails type, layout, and copy. Checklist ending in "color-clear → stop" causes silent false-negatives.
Fix
Make every gate pass NECESSARY, NOT SUFFICIENT for the overall verdict. Run the full dimension rubric.
Check
Verify if any gate ends in "and stop". Every gate must declare what it clears and what remains.
CASE №018design · exemplarsfixed

Bless-with-variety, not one exemplar

Scar
A gate naming ONE passing example quietly blesses it as the new safe default — the corpus re-converges on that crowned pass case.
Fix
Vary the exemplar across archetypes/hue families in the same clause (cool cobalt, green chlorophyll, warm gilt) so no single look dominates.
Check
Check if pass-examples repeat one fixed swatch; diversify across archetypes.
CASE №019design · mediumfixed

Medium-aware tells

Scar
A web anti-slop checklist (centered hero, hover-only, CTA line-wrap) is nonsense on a physical or print surface. Judging a poster by hover-only is a false fail.
Fix
Scope each tells-list to its medium: web to screen only; physical/print to material, shape, and substrate.
Check
Verify if tells could even exist on a print poster or device; if not, label web-only.
