REV 024android · share-sheetcorrected

Kotlin putExtra IPC crash on ArrayList

Symptom
Multi-file share crashes at Binder IPC with NotSerializableException.
Cause
intent.putExtra() resolves to Serializable overload for ArrayList<Uri>
Fix
Call intent.putParcelableArrayListExtra(EXTRA_STREAM, list) explicitly.
Check
grep -rn "putExtra.*EXTRA_STREAM.*ArrayList" app/ returns zero results.
REV 020flutter · drift-dbcorrected

Drift column named text breaks codegen

Symptom
build_runner produces an empty stub database.g.dart without compiler error.
Cause
TextColumn get text => text()() collides with Table.text() DSL builder
Fix
Name column note, content, or body - never text.
Check
grep -rn "TextColumn get text" lib/db/ returns zero results.
REV 004rust · android-imecorrected

Host process death by unwrap

Symptom
IME crash-loops on device. No stack trace survives.
Cause
panic="abort" + .unwrap() on poisoned lock in JNI path
Fix
Three lines - recover via poisoned.into_inner().
Check
grep unwrap() in every extern fn before release.
REV 009kotlin · settingscorrected

The button that lied

Symptom
User believes clipboard history deleted. It wasn't.
Cause
click listener ends at Toast.makeText() - success toast, zero mutation
Fix
Destructive handler must touch storage or propagate error.
Check
Grep delete/clear/reset listeners; each body must mutate or fail loudly.
