Silent codegen stubs and compileSdk traps.

Lessons from building an offline-first life tracker with Flutter, Drift, and Android 16. DSL collisions and Gradle toolchain breaks.

case files / flutter ward

CASE №020flutter · drift-dbfixed

Drift column named text silently breaks codegen

Scar
Naming a Drift schema column TextColumn get text => text()() collides with Drift's Table.text() DSL builder. build_runner produces an empty stub database.g.dart with no compiler error, causing cascade missing-class failures.
Fix
Name the column note, content, or body - never text.
Check
grep -rn "TextColumn get text" lib/db/ must return zero results.
CASE №021flutter · symbolsfixed

Drift query builders collide with flutter_test and widgets

Scar
Importing package:drift/drift.dart in test files exports isNull and isNotNull, which collide with package:matcher. In UI files, Drift's Column and Table collide with Flutter layout widgets.
Fix
Hide colliding symbols on import: hide isNull, isNotNull in tests; hide Column, Table in widget files.
Check
flutter analyze flags ambiguous_import immediately on collision.
CASE №022flutter · toolchainfixed

Legacy plugin hardcodes compileSdk 34 vs AGP 36 requirement

Scar
Older plugin versions hardcode compileSdk 34 in their inner android/build.gradle. When app dependencies require API 36, checkReleaseAarMetadata fails even if the root app specifies compileSdk = 36.
Fix
Bump the plugin to a federated version using compileSdk flutter.compileSdkVersion.
Check
flutter build apk --release --target-platform android-arm64 runs checkReleaseAarMetadata cleanly.
CASE №023flutter · agp9fixed

AGP 9+ / Built-in Kotlin breaks legacy KGP plugin registration

Scar
AGP 9+ with android.builtInKotlin=true fails during compileReleaseJavaWithJavac with cannot find symbol in GeneratedPluginRegistrant.java if a plugin applies legacy KGP.
Fix
Upgrade to federated plugin packages supporting Built-in Kotlin, or migrate away from plugins lacking modern AGP support.
Check
GeneratedPluginRegistrant.java compiles without missing symbol errors.
