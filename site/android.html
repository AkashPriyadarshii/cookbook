The share sheet drops silently or crashes at IPC.

Lessons from building ExifDrop, an offline zero-UI share trampoline for Android. Intent overload traps, unpopulated clipData, and sandbox traversal.

CASE №024android · ipcfixed

Kotlin putExtra marks ArrayList<Uri> as Serializable over IPC

Scar
In ACTION_SEND_MULTIPLE, passing ArrayList<Uri> via intent.putExtra() resolves to putExtra(String, Serializable) in Kotlin. Android flags the extra Serializable. During Binder IPC, Java serialization fails on Uri with NotSerializableException.
Fix
Call intent.putParcelableArrayListExtra(Intent.EXTRA_STREAM, ArrayList(uris)) explicitly.
Check
grep -rn "putExtra.*EXTRA_STREAM.*ArrayList" app/ returns zero results.
CASE №025android · share-sheetfixed

ACTION_SEND_MULTIPLE fallback: clipData == null drops the batch

Scar
Legacy sending apps frequently send ACTION_SEND_MULTIPLE with clipData == null. If the fallback calls getParcelableExtra(EXTRA_STREAM, Uri::class), it returns null because the extra is an ArrayList. The batch drops silently with zero feedback.
Fix
Branch on ACTION_SEND_MULTIPLE and call IntentCompat.getParcelableArrayListExtra(intent, EXTRA_STREAM, Uri::class.java).
Check
Test Intent(ACTION_SEND_MULTIPLE) with clipData = null and EXTRA_STREAM = arrayListOf(u1, u2).
CASE №026android · sandbox-securityfixed

Untrusted DISPLAY_NAME escapes sandbox via path traversal

Scar
Querying OpenableColumns.DISPLAY_NAME from an external ContentProvider returns untrusted input. A hostile provider sends ../../shared_prefs/app.xml. File(cacheDir, name) allows directory traversal and private file overwrites.
Fix
Sanitize to a bare basename: filter to [a-zA-Z0-9 _-.], collapse .. to _, and trim leading/trailing dots.
Check
Unit test passing ../../../shared_prefs/app.xml; assert output stays strictly inside cache dir.
CASE №027android · share-sheetfixed

EXTRA_EXCLUDE_COMPONENTS is silently ignored on Android < 13

Scar
EXTRA_EXCLUDE_COMPONENTS prevents self-selection in chooser sheets, but it was only added in API 33. On API 24–32, Android silently ignores it, causing infinite re-share loops if the user picks the trampoline again.
Fix
Pair EXTRA_EXCLUDE_COMPONENTS with an incoming URI authority loop-breaker: if (uri.authority == "$packageName.fileprovider") return.
Check
Launch share target with own FileProvider URI; verify it drops without opening a chooser.
